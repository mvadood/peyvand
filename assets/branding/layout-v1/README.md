# Conversation layout v1 — quick draft

Created 2026-09-28 for fast visual iteration. Not approved or integrated into episode rendering.

- `conversation-2.png`: actual Milad and Hooman footage at source time 145 seconds.
- `conversation-3.png`: same speakers plus an explicitly labelled third-speaker placeholder. No third-person recording was available in the current episode.
- Matching SVG files are editable and contain embedded frame cutouts.
- `milad.png` and `hooman.png` were extracted from the recordings with the existing alpha video mattes through FFmpeg. Source crops: Milad 1300×1100 at (630,160); Hooman 760×642 at (610,420), then scaled to width 1000.
- `build_mockup.py` rebuilds both SVG/PNG compositions using rsvg-convert; no full episode render.

The mockup explores light grey panels, compact Persian topic heading, name labels, the approved logo and a caption band. Caption comes from the existing cue at 145 seconds. Name labels represent their brief introductory state, not a requirement to leave them visible throughout the episode. Typography and matte edges remain draft quality for this quick review.
