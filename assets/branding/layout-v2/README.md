# Conversation layout v2 — draft

Quick revision after v1 was rejected for feeling plain and like a Zoom call, with poor fonts.

`conversation-focus.png` / `.svg`: dominant Hooman shot, smaller Milad reaction, oversized native logo stroke, dark neutral backdrop, and Vazirmatn Bold with proper Persian shaping. Uses the same real footage cutouts from v1. “مسئله کجاست؟” is a proposed editorial topic heading, not a quote. Name labels illustrate a brief introduction; the large topic title is intended for a topic beat, rather than the whole episode.

Font source: https://github.com/rastikerdar/vazirmatn (OFL license saved alongside the font). `build_mockup.py` rebuilds the native SVG composition and PNG with Pillow RAQM and rsvg-convert. This is a draft, not approved or integrated into the renderer. Matte quality remains inherited from the existing video masks.
